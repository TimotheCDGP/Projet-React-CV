# Pour démarrer le projet :
- Installer MongoDB
- Se placer dans /backend et /frontend respectivement et faire ```npm i```
- Faire ```.\mongod --dbpath="\backend\data\"```  // Choisissez un chemin valide pour la base de données, cela va lancer et/ou installer la base de données
- Faire ```cd \backend & node server.js``` pour lancer le serveur
- Amusez-vous bien !
